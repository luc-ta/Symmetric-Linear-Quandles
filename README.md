# Symmetric-Linear-Quandles
GAP program for computing good involutions of finite linear Alexander quandles. Complete data up to order 23, partial data up to order 29.

Created by Lực Ta

See Section 5 of the paper ["Good involutions of twisted conjugation subquandles and Alexander quandles"](https://arxiv.org/abs/2508.16772) for enumerations and further information.
